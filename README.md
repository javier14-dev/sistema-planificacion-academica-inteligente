# Sistema de Planificación Académica Inteligente

Proyecto final del curso de Programación Avanzada.

## Descripción

Sistema orientado a objetos que permite organizar y planificar actividades académicas mediante la gestión de:

- Usuarios
- Cursos
- Unidades
- Temas
- Recursos
- Sesiones de estudio
- Evaluaciones
- Recordatorios
- Progreso académico

El proyecto está desarrollado en TypeScript utilizando arquitectura por capas:

- domain
- application
- interface

## Estructura del Proyecto

src/
- domain → Entidades del sistema
- application → Casos de uso
- interface → Interfaz por consola

## Tecnologías

- TypeScript
- Node.js
